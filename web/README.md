# Web version

`power-system-basics.html` is the source of the published page:
https://claude.ai/artifact/CNg9KrHXyNkaiGcmMBEQQq

It has no `<!doctype>`, `<html>`, `<head>` or `<body>` tags on purpose. claude.ai adds them when it publishes the page. Opening the file directly in a browser still works, because browsers add the missing tags themselves.

To update the page, edit this file and republish it to the same artifact link.
